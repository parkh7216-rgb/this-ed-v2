# 우리 국어하자

맞춤법 조항별 연습, 지문 학습, 사용자가 직접 넣은 지문으로 만드는 AI 독해 문제를 제공하는 웹 앱입니다.

## 실행

Node.js 22 이상에서 프로젝트 폴더로 이동한 뒤 `node server.js`를 실행하세요. 기본 포트는 `3000`이며 `PORT` 환경 변수로 바꿀 수 있습니다.

AI 문제 생성을 쓰려면 서버 실행 환경에 `MANUS_API_URL`과 `MANUS_API_KEY`를 설정해야 합니다. 키 값은 소스 코드나 저장소에 넣지 마세요. API 서버는 사용자가 추가한 지문만 근거로 고난도 5지선다 독해 문항 5개와 근거·해설을 생성하도록 설계되어 있습니다.

## 검사

```bash
node --check app.js
node --check server.js
node --test tests/server.test.js
```

## 자료 추가

교재 지문은 원문을 받은 뒤에만 `지문` 자료로 추가합니다. 원문이 오기 전에는 임의의 지문을 넣지 않습니다. 맞춤법 조항·보기형 문제는 `맞춤법` 학습에 포함됩니다.

## 배포 참고

이 앱의 AI 문제 생성은 Node.js 서버의 `/api/generate`를 사용합니다. GitHub Pages는 정적 파일만 제공하므로, GitHub Pages만으로는 AI API를 실행할 수 없습니다. 공개 배포 전에는 서버를 실행할 백엔드 호스팅을 별도로 구성해야 합니다.
